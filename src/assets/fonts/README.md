# Self-hosted fonts

Latin variable WOFF2 subsets of Inter (400–800) and Syne (600–800), obtained from Google Fonts. Both use the SIL Open Font License; the license files are included here.

The family names, styles and weights match the previous Google Fonts stylesheet. Browser/system fallbacks continue to cover characters outside the Latin subset. Fonts are emitted as hashed Vite assets and use the existing immutable asset cache.
